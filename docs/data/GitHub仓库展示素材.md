## 2. GitHub 仓库简介（可直接复制）

### 中文版
一个面向节假日短途出行场景的旅行地推荐 MVP，重点解决“不知道去哪”和“不想人挤人”。

### 英文版
An MVP for holiday short-trip destination recommendations, focused on helping users avoid crowded places during public holidays.

## 4. 适合公开发布时的说明文案

### 短版
正在做一个节假日旅行地推荐工具 MVP，先聚焦端午 / 短假 / 不想人挤人这个场景。仓库里记录了产品 PRD、推荐逻辑、候选地配置和研究脚本。

### 长版
这是一个还在验证阶段的旅行推荐产品 MVP，目标不是做一个大而全的攻略网站，而是帮助用户在节假日短途出行时，更快找到“这次更适合自己、又没那么挤”的目的地。当前版本聚焦北上广深年轻人的端午 3 天短假场景，仓库中包含了产品文档、推荐引擎、候选地配置，以及基于 Tavily 的候选地研究脚本。
