# 小红书投放测试方案 v1

## 1. 测试目标

当前不是做大规模投流，而是验证三个问题：

1. 用户是否真的有“节假日不知道去哪”的痛点
2. “不想人挤人”是否是一个足够强的点击理由
3. 用户是否愿意使用一个轻量工具来获取推荐，而不是继续手动刷攻略

换句话说，第一轮小红书测试的目标是：

> 先验证需求和表达，不是先追求爆款。

## 2. 核心假设

### 假设 A：痛点成立
“端午只有 3 天，不想人挤人，也不知道去哪” 是真实且常见的问题。

### 假设 B：表达要具体
比起“旅行推荐工具”，用户更容易被下面这类表达打动：

- 端午不想人挤人去哪
- 3 天短假还有哪里值得去
- 不想去热门景区，有没有替代目的地
- 从上海 / 广州 / 深圳出发，端午还能去哪

### 假设 C：内容要像经验分享，而不是硬推产品
用户更愿意点进来的是：

- 你帮他节省决策时间
- 你替他筛掉不合适的目的地
- 你像一个做过功课的人

而不是：

- 我做了个产品，欢迎体验

## 3. 第一轮内容策略

建议第一轮不要只发一种内容，而是发 **3 类笔记**：

### 类型 1：痛点型
目标：验证“痛点表达”能不能打动用户。

标题示例：
- 端午只有 3 天，不想人挤人到底该去哪？
- 别再无脑冲热门城市了，端午短假真的会累
- 如果你端午不想人挤人，我帮你筛了 24 个候选地

内容结构：
1. 先讲痛点
2. 再讲为什么热门目的地不适合
3. 再抛出“我做了个小工具在筛这件事”
4. 最后引导评论 / 私信 / 点击

### 类型 2：清单型
目标：验证“候选地本身”有没有吸引力。

标题示例：
- 端午 3 天，适合上海出发的 6 个相对不挤目的地
- 广深出发，端午不想人挤人可以考虑这 5 个地方
- 北京出发，端午想看海但不想太挤，我会先看这几个地方

内容结构：
1. 明确出发城市
2. 直接给候选地
3. 每个候选地给一句为什么
4. 最后补一句：我把它们做成了一个推荐工具

### 类型 3：产品验证型
目标：验证用户是否愿意点击和使用。

标题示例：
- 我做了个“端午避挤旅行推荐助手”，想测下有没有人需要
- 因为我自己每次节假日都不知道去哪，所以做了这个小工具
- 输入出发地和偏好，给你几个更适合端午短假的目的地

内容结构：
1. 讲自己的动机
2. 展示产品界面
3. 展示 1~2 个真实推荐案例
4. 引导用户留言自己的出发地 / 偏好

## 4. 推荐的测试顺序

建议顺序：

1. **先发痛点型 + 清单型**
2. 再发产品验证型

原因：

- 用户先对问题感兴趣，才会对工具感兴趣
- 一上来就发“我做了个产品”，很容易没点击
- 小红书更适合先讲场景，再带出工具

## 5. 建议首批测试主题

### 主题 A：上海出发
因为上海周边短途出行心智最强，容易形成具体需求。

可测标题：
- 端午 3 天，上海出发不想人挤人还能去哪？
- 我不会优先去苏州杭州了，端午短假更想去这些地方

### 主题 B：广深出发
因为广深用户对“高铁 2~3 小时 + 松弛出游”很敏感。

可测标题：
- 广州 / 深圳出发，端午不想挤，我会先看这几个地方
- 比珠海更稳、比热门海边轻松，端午短假可以看看这些地方

### 主题 C：北京出发
因为海边短假是天然需求。

可测标题：
- 北京出发，端午想看海但不想太挤，我会先看这几个地方
- 端午 3 天，北京周边海边怎么选才不容易踩坑

## 6. 指标怎么判断

第一轮重点看这些指标：

### 内容层
- 点击率 / 打开率
- 收藏率
- 评论数
- 评论中是否出现“求链接 / 求推荐 / 我也是这样”

### 产品层
- 有多少人真的点进来
- 有多少人愿意输入条件做推荐
- 有多少人愿意留言自己的出发地和偏好

### 判断标准
如果出现以下信号，就说明方向成立：

- 评论区有人说“我也正在想这个问题”
- 有人追问某个出发城市的替代地
- 有人主动要链接 / 要工具
- 不同城市的人群都能形成互动

## 7. 首轮不要犯的错误

### 错误 1：把内容写成产品说明书
用户不会因为你做了个工具就自动感兴趣。

### 错误 2：一上来就讲算法和推荐逻辑
用户更在意“这次我去哪比较合适”。

### 错误 3：只强调“人少”
“人少”要和下面这些词一起出现才更有吸引力：

- 值得去
- 不折腾
- 3 天刚好
- 高铁方便
- 松弛感

## 8. 建议的笔记结构模板

### 模板一：痛点型
1. 开头一句强共鸣
2. 中间列出 3 个常见错误目的地选择
3. 再给 3~5 个替代候选地
4. 最后说：我把这件事做成了一个小工具，想继续测测有没有人需要

### 模板二：清单型
1. 明确出发城市
2. 给 5 个目的地
3. 每个一句理由
4. 结尾 CTA：如果你也卡在端午不知道去哪，可以留言你的出发地

### 模板三：产品型
1. 为什么做
2. 产品界面截图
3. 一个输入示例
4. 一个输出示例
5. CTA：想试的话我放评论区 / 主页

## 9. 建议的 CTA

第一轮 CTA 不要太硬，建议用：

- 如果你也正在纠结端午去哪，可以留言你的出发地
- 如果你想测测适合去哪，我可以继续放一些示例
- 如果这个方向有人需要，我就把它继续做下去

而不是直接硬喊：

- 快来用
- 点链接体验
- 帮我转发

## 10. 下一步建议

建议你的小红书投放测试按这个节奏走：

1. 先准备 3 篇不同角度的笔记
2. 每篇都带上一个明确城市场景
3. 用真实页面截图做证明
4. 看哪一类标题和评论反馈最好
5. 再根据反馈迭代 landing page 和推荐逻辑
