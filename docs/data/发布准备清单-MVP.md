# 发布准备清单 - MVP

## 一、功能层

- [ ] 首页可正常加载
- [ ] 推荐接口可正常返回结果
- [ ] 换一批逻辑正常
- [ ] 目的地候选池足够支撑多轮推荐
- [ ] Tavily 单目的地研究脚本可运行
- [ ] Tavily 批量研究脚本可运行

## 二、配置层

- [ ] `.env.local` 已配置 `TAVILY_API_KEY`
- [ ] 不把密钥暴露到前端
- [ ] 候选地 JSON 已校准到最新版本
- [ ] `docs/research/` 中已有第一批研究结果

## 三、产品层

- [ ] 首页文案突出“端午避挤”
- [ ] 推荐结果体现“为什么推荐”
- [ ] 风险提示可见
- [ ] 候选地不少于 24 个

## 四、发布层

- [ ] 明确部署方式（Vercel / Railway / Render / 自建 Node）
- [ ] 明确环境变量注入方式
- [ ] 增加基础 README
- [ ] 梳理一份对外演示话术
- [ ] 上线前做一轮真机体验

## 建议顺序

1. 跑通 Tavily 批量研究
2. 根据结果更新候选地配置表
3. 补 README
4. 选择部署平台并发布
